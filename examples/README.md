# Examples

The separately downloadable `exosearch-ai-demo.zip` contains a synthetic 350-star offline end-to-end demonstration with `index.html`, `plotly.min.js`, the sample CSV, generated evaluation metrics, and ranking output. Open `index.html` from the extracted archive.

The repo intentionally excludes real NASA catalog tables and generated model artifacts. Use `exosearch demo` to regenerate the synthetic version locally, and `exosearch fetch` / `train` to reproduce a real-data experiment after obtaining a NASA TOI snapshot.
