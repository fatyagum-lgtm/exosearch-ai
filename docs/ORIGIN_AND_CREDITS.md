# Project history and independent reconstruction

The original **ExoSearch_AI — Exoplanet Detection Model** was prepared for FIU course **CAI 4002** under Professor Yanzhao Wu, with a report dated **April 25, 2026**.

Listed group members: **Maria Amaya**, **Fatima Humbatova**, **Adrian Perez Galindo**, **Maksim Pikalov**.

Fatima states that she led the original project. The available report explicitly identifies Adrian as coordinating Google Docs, slides, the old GitHub repository, submissions, and team communications; its individual-contribution sections for several members are blank. Those are compatible with different leadership and coordination responsibilities, but the report alone does not independently establish the complete contribution breakdown.

The report describes the objective, NASA TESS data, Logistic Regression / XGBoost approach, and planned comparison methodology. It does **not** contain verified numerical model results or a usable code release.

**This repository does not purport to reproduce the lost historical implementation.** It is a new independent codebase built from the original research direction. Dates of this code, its commits, evaluation artifacts, and screenshots relate only to the reconstruction, not to the past team deliverables.

No claim is made that NASA endorsed the code or that it has discovered or confirmed an exoplanet. Credit to the original project team is preserved without implying they wrote this new source code.
